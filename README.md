# 🔧 BaseCalc Plumbing

Field-ready plumbing calculators and job records for technicians, installers, and service contractors, built with Expo / React Native. Run water, drainage, gas, pressure, and fixture calculations on the job site, save the result, and turn the work into a field-ticket PDF you can hand off to SpeakSheet for final billing. BaseCalc Plumbing is device-local by design: no BaseCalc account, cloud sync, or cloud database is required.

## Features

**Calculators (18 plumbing field tools)**
- **Pipe Velocity** — velocity from GPM and nominal pipe size
- **Flow Rate** — GPM from velocity and nominal pipe size
- **Pipe Sizing** — minimum pipe size from GPM and max velocity
- **Pressure Drop** — Hazen-Williams pressure loss
- **Drainage Sizing** — fixture units → minimum drainage pipe diameter
- **Vent Sizing** — fixture units + vent length → minimum vent diameter
- **Water Heater** — first-hour rating / recovery estimate
- **Gas Pipe Sizing** — BTU/hr + length → minimum gas pipe size
- **Pump Head** — total dynamic head from lift, friction, and pressure
- **Pipe Volume** — gallons of water in a given length of pipe
- **Water Pressure** — pressure ↔ head conversion
- **Pipe Expansion** — thermal expansion length change
- **Fixture Units** — count common fixtures → total fixture units
- **Water Meter Sizing** — fixture units → meter size
- **Irrigation Flow** — zone GPM from heads × GPM per head
- **Septic Tank** — bedrooms / daily flow → minimum tank volume
- **Grease Interceptor** — fixture units / GPM → interceptor size
- **Backflow Pressure** — pressure loss across backflow preventer

Every result shows a clear readout, the governing limit where applicable, and a full breakdown.

**Field workflow**
- Job contacts for field-ticket context
- Field tickets with workup items, notes, and PDF export
- Job state tracking (draft / ready / closed / review)
- Materials pull-list starters
- On-device calculation history
- Light & dark themes (dark, high-contrast "field instrument" UI)

## Tech stack

Expo SDK 56 · React Native 0.85 · TypeScript · React Navigation · Zustand (persisted via AsyncStorage) · NativeWind · expo-sqlite · expo-print · RevenueCat. Typography: Saira + JetBrains Mono.

## Development

```bash
npm install
npm run ios        # build & run on the iOS simulator (requires prebuild or native dirs)
npm test           # Jest unit tests (calculation engine)
npx tsc --noEmit   # type-check
```

Brand assets (icon, splash, adaptive icons, grid tiles, glow, and lockup logos) are generated by `scripts/generate-brand-assets.mjs`.

## Project structure

```
App.tsx                       # navigation, theme provider, font loading
src/engine/PlumbingEngine.ts  # pure calculation logic (unit-tested)
src/screens/                  # calculators, jobs, materials, history, settings
src/components/               # Type.tsx (typography), ui.tsx (instrument UI kit)
src/theme/                    # color tokens, typography, theme provider
src/store/                    # Zustand store (job contacts, field tickets, calculations)
src/services/                 # field-ticket PDF export, analytics
__tests__/                    # PlumbingEngine tests
```

## Release setup

Before submitting to the stores:
1. Create a new Expo project / EAS project ID and update `app.config.js`.
2. Create a new App Store Connect app and update `eas.json` (`submit.production.ios.ascAppId`).
3. Update the Google Play service account path in `eas.json` if needed.
4. Regenerate store screenshots with `scripts/generate-store-screenshots.mjs` after updating its calculator list copy.
5. Verify all URLs in `store.config.json` and `STORE_LISTING.md` point to live plumbing pages.
